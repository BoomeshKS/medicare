# Medicare - Healthcare Landing Page

## Overview

Medicare is a modern and responsive healthcare landing page designed to provide users with information about medical services, online consultations, healthcare features, and appointment booking. The website focuses on delivering a clean user experience with smooth animations and mobile-friendly design.

## Tech Stack

### Frontend

* React.js
* JavaScript (ES6+)
* Tailwind CSS

### Animation Library

* Framer Motion

### Icons Library

* React Icons

### Build Tool

* Vite

## Libraries Used

### React

Used for building reusable and interactive user interface components.

### Tailwind CSS

Used for responsive styling and rapid UI development with utility-first classes.

### Framer Motion

Used to create smooth animations, transitions, and interactive effects throughout the website.

### React Icons

Used to provide scalable and customizable icons for healthcare-related actions and navigation.

## Installation

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to Project Directory

```bash
cd medicare
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
